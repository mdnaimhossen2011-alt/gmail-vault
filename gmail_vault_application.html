আপনার নিরাপদ পাসওয়ার্ড ম্যানেজার

কোনো জিমেইল অ্যাকাউন্ট পাওয়া যায়নি!

আপনার সংরক্ষিত কোনো জিমেইল অ্যাড্রেস নেই অথবা অনুসন্ধানের সাথে মেলেনি।

সিকিউরিটি পিন দিন

পাসওয়ার্ডটি দেখার জন্য আপনার গোপন মাস্টার পিনটি দিন

ভুল সিকিউরিটি পিন! আবার চেষ্টা করুন।

নতুন জিমেইল যোগ করুন

আপনার নিরাপদ জিমেইল ও পাসওয়ার্ড এনক্রিপ্ট হয়ে থাকবে

ডেটা ব্যাকআপ ও রিস্টোর

গিটহাব পেজে ব্যবহারের জন্য ফাইল ব্যাকআপ রাখুন

ব্যাকআপ নামিয়ে নিন (Export)

আপনার সকল এনক্রিপ্ট করা তথ্য সুরক্ষিত JSON ফাইল হিসাবে ডাউনলোড করুন।

রিস্টোর করুন (Import)

পূর্বে সেভ করা JSON ফাইল আপলোড করে অ্যাকাউন্ট রিস্টোর করুন।

মাস্টার পিন সেটিং

পাসওয়ার্ড সুরক্ষিত রাখার জন্য ৪-৮ ডিজিটের পিন সেট করুন

গিটহাব পেজে ফ্রিতে লাইভ করার নির্দেশিকা

খুব সহজেই ১ মিনিটেই আপনার নিজের গিটহাব অ্যাকাউন্টে এই সাইটটি সেটআপ করুন

১

গিটহাবে নতুন Repository খুলুন

আপনার GitHub অ্যাকাউন্টে যান এবং New Repository তে ক্লিক করুন। Repository Name দিন যেমন: gmail-vault। Public সিলেক্ট রাখুন।

২

কোড ফাইলটি ডাউনলোড করুন

এই পেজের সম্পূর্ণ HTML/JS কোড কপি করে আপনার পিসিতে index.html নামে সেভ করুন।

৩

ফাইল আপলোড করুন (Upload files)

গিটহাব রিপোজিটরির ভেতর uploading an existing file লিংকে ক্লিক করে আপনার index.html ফাইলটি আপলোড করে Commit changes চাপুন।

৪

GitHub Pages অন করুন

রিপোজিটরির Settings -> Pages সেকশনে যান। Build and deployment এ Branch হিসেবে main সিলেক্ট করুন এবং Save করুন।
